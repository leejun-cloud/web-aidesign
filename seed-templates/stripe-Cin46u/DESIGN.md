## Design Direction
Stripe — 분위기: clean, confident, vibrant, modern, trustworthy, energetic. hero 구조: 좌측 정렬 텍스트 블록(상단 라벨 → 대형 헤드라인 2줄 → 2개 CTA 버튼 가로 배치) 위에 우측에서 대각선으로 흘러드는 풀블리드 그라디언트 일러스트가 겹쳐지는 비대칭 히어로

## Color System
background #FFFFFF / surface #FDFBFF / primary #635BFF / secondary #4B5B74 / accent #FF8A3D / text #1A1F36. 채도 배경은 무채색에 가깝지만 히어로 그래픽은 고채도의 보색 대비가 두드러짐, 색온도 중립 바탕에 보라-오렌지-핑크가 섞인 난색/한색 혼합 톤

## Typography
군더더기 없는 그로테스크 산세리프, 중립적이면서 기술 지향적인 인상. 스케일 본문 대비 헤드라인 크기 비율이 큰 폭으로 확대되어 약 4~5배 차이, 굵기 헤드라인은 세미볼드~볼드, 본문은 레귤러로 두 단계 대비, 행간 헤드라인은 자간이 촘촘한 1.1~1.2배 줄간격, 본문은 여유 있는 1.4~1.5배, 자간 기본 자간 유지, 과도한 확장이나 압축 없음. 위계: 소형 라벨 텍스트 → 대형 멀티라인 헤드라인 → 중간 크기 보조 설명문 → 버튼 레이블 순으로 뚜렷한 4단계 위계

## Spacing
섹션 간격 섹션 간 넉넉한 수직 여백, 뷰포트 높이의 10~15% 수준, 컨테이너 패딩 좌우 컨테이너 패딩은 데스크톱 기준 넓게, 모바일에서는 축소되어 약 1/3 수준으로 좁아짐, 카드 패딩 로고 아이템 간 내부 여백은 작고 균일, 콘텐츠 간격 라벨-헤드라인-버튼 사이 각각 명확한 간격 단위로 구분되는 리듬, hero 여백 헤드라인 좌측과 상단에 넓은 여백을 두어 텍스트가 호흡할 공간을 확보

## Layout
컨테이너 콘텐츠는 뷰포트 폭의 약 55~60%에 좌측 정렬되고 우측 40~45%는 비주얼이 차지하는 비대칭 컨테이너, 정렬 좌측 정렬, 헤드라인과 버튼 모두 왼쪽 기준선 고정, 이미지 배치 히어로 우측 상단에서 하단으로 대각선 리본 형태의 비주얼이 텍스트 뒤 배경처럼 걸쳐짐

## Grid
단일 컬럼 콘텐츠 트랙, 로고 바는 7~8개 아이템 균등 가로 나열의 플렉스 그리드. 섹션 순서: header → hero → logoBar → featureIntro

## Photography
구도 구상 사진이 아닌 추상 그라디언트 리본이 프레임 우측을 대각선으로 가로지르는 구성, 조명 광원 느낌의 밝은 중심부에서 가장자리로 번지는 소프트 글로우, 그레이딩 보라-핑크-오렌지로 이어지는 연속적 무지개 그라디언트 톤매핑, 화각 해당 없음(평면 그래픽 요소), 심도 해당 없음, 플랫한 벡터형 그라디언트 레이어, 비율 풀블리드 와이드 비율로 히어로 섹션 우측 40~50%를 채움

## Components
테두리 헤더 하단에 1px 연한 회색 구분선, 버튼 테두리는 얇은 1px 라인, 라운드 버튼과 팝업 패널 모두 약 6~8px의 중간 라운드 코너, 그림자 쿠키 배너 패널에 은은한 하단 플로팅 섀도, 전반적으로 그림자 사용은 절제됨

## Navigation
드롭다운 화살표가 달린 텍스트 링크 메뉴, 호버 시 서브메뉴가 열리는 구조 추정

## Buttons
채움형 기본 버튼(진한 보라 배경 + 흰 텍스트 + 화살표 아이콘)과 외곽선형 보조 버튼(흰 배경 + 얇은 보라 테두리) 두 종류가 나란히 배치

## Forms
쿠키 배너 내 단순 텍스트 + 2개 버튼 조합의 미니멀 패널 형태

## Cards
별도 그림자 카드 없이 로고들은 플랫한 가로 리스트로 노출

## Motion
fade 헤드라인 텍스트 일부가 색상 전환으로 서서히 강조되는 듯한 그라디언트 틴트 효과 / reveal 스크롤 시 섹션이 아래에서 위로 부드럽게 드러나는 리빌 추정 / scroll 배경 그라디언트가 스크롤에 따라 미세하게 시차 이동하는 패럴랙스 느낌 추정 / hover 버튼 호버 시 약간의 밝기 변화 또는 미세 확대 반응 추정 / transition 전반적으로 200~300ms 수준의 짧고 부드러운 이징 전환

## Responsive
