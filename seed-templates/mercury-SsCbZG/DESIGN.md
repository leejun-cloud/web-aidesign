## Design Direction
Mercury — 분위기: 간결한, 신뢰감 있는, 테크 지향적, 절제된, 프리미엄. hero 구조: 좌측 2단 텍스트 블록(헤드라인+불릿형 제품 리스트) 대 우측 플로팅 대시보드 카드 패널의 비대칭 2컬럼 구성, 모바일은 풀블리드 배경 사진 위에 중앙 정렬 텍스트+입력폼+버튼 스택

## Color System
background #0A0A0F / surface #15151C / primary #5B6CFF / secondary #8C8C99 / accent #6C7BFF / text #F2F2F5. 채도 배경과 표면은 거의 무채색에 가까운 저채도, 액션 요소에만 채도 높은 보라빛 블루 포인트, 색온도 전반적으로 차가운 톤의 다크 테마, 포인트 컬러만 살짝 따뜻한 보랏빛 블루

## Typography
군더더기 없는 그로테스크 산세리프, 중립적이고 기술적인 인상. 스케일 히어로 헤드라인은 2줄 구성의 큰 사이즈(대략 36~44px급), 본문 대비 확연한 크기 차이, 굵기 헤드라인은 레귤러~미디엄 굵기로 과장되지 않게, 리스트 제목은 세미볼드로 약간 강조, 행간 헤드라인은 타이트한 줄간격, 본문 설명 텍스트는 여유 있는 줄간격, 자간 로고와 네비게이션 라벨에 약간의 자간 확장, 본문은 기본 자간. 위계: 헤드라인-구분선-굵은 리스트 제목-설명문 순으로 단계가 명확히 분리되는 구조

## Spacing
섹션 간격 섹션 간 넉넉한 수직 여백으로 콘텐츠 블록을 분리, 컨테이너 패딩 데스크톱 좌우 큰 여백, 모바일은 좁고 일관된 좌우 패딩, 카드 패딩 카드 내부에 중간 정도의 여유로운 패딩, 콘텐츠 간격 리스트 항목 사이는 얇은 구분선과 함께 적당한 간격 유지, hero 여백 헤드라인 위아래로 큰 여백을 두어 시선을 집중시키는 넉넉한 히어로 여백

## Layout
컨테이너 최대 1400px 내외의 와이드 컨테이너에 좌우 넉넉한 여백, 정렬 데스크톱 좌측 텍스트는 좌측 정렬, 모바일은 중앙 정렬, 이미지 배치 데스크톱은 히어로 우측에 떠있는 듯한 UI 카드 목업을 배치, 모바일은 상단 텍스트 아래 전체 폭 배경 사진

## Grid
넓은 거터를 둔 12컬럼 비대칭 그리드, 좌우 컬럼 비율 약 45:55. 섹션 순서: header → hero → productList → dashboardPreview

## Photography
구도 드넓은 자연 풍경 속에 사무용 책상과 의자를 이질적으로 배치한 초현실적 구도, 조명 일출/일몰 시간대의 측광, 부드럽고 확산된 안개 낀 조명, 그레이딩 저채도 파스텔톤에 보라-주황 계열 색보정을 더한 시네마틱 그레이딩, 화각 낮은 눈높이에서 피사체를 올려다보는 약간의 로우앵글, 심도 전경 피사체는 선명하게, 배경 산세는 자연스럽게 흐려지는 얕지 않은 심도, 비율 모바일 히어로는 세로로 긴 비율(약 9:16에 가까운 풀스크린), 데스크톱은 카드형 썸네일의 정방형에 가까운 비율

## Components
테두리 1px 내외의 저명도 반투명 테두리선을 표면 구분에 사용, 라운드 버튼과 입력창은 완전 둥근 알약형, 카드와 패널은 중간 정도의 둥근 모서리, 그림자 다크 배경 위에 은은하게 발광하는 듯한 부드러운 그림자로 카드의 부유감 표현

## Navigation
가로 배치 텍스트 링크와 쉐브론 아이콘이 붙은 드롭다운 메뉴 조합

## Buttons
알약형(완전 둥근) 단색 채움 버튼과 테두리만 있는 아웃라인 버튼을 쌍으로 배치, 텍스트는 중간 굵기

## Forms
둥근 알약형 단일 입력 필드, 테두리만 있는 미니멀한 스타일

## Cards
어두운 반투명 표면에 옅은 테두리를 두른 플로팅 패널형 카드, 리스트 항목은 가는 구분선으로만 분리

## Motion
fade 스크롤 진입 시 콘텐츠가 은은하게 페이드인되는 정도로 절제된 사용 / reveal 카드와 리스트 항목이 순차적으로 약하게 드러나는 가벼운 리빌 / scroll 패럴랙스 없이 일반적인 수직 스크롤 흐름 / hover 버튼과 리스트 항목에 마우스 오버 시 미세한 밝기/배경 변화 / transition 전반적으로 짧고 부드러운 이징의 절제된 트랜지션

## Responsive
브레이크포인트: 834px, 1440px, 540px, 1100px
