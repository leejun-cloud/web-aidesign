## Design Direction
Notion — 분위기: clean, confident, playful-minimal, high-contrast, modern, trustworthy. hero 구조: 중앙 정렬 텍스트 히어로 — 상단 네비게이션 아래 큰 헤드라인, 서브카피, 버튼 2개(주 CTA + 보조 CTA)가 세로로 쌓이고 그 아래 제품 스크린샷 프리뷰가 뷰포트 하단에 걸치듯 배치됨

## Color System
background #FFFFFF / surface #F7F7F5 / primary #111111 / secondary #C7E8CB / accent #2383E2 / text #1A1A1A. 채도 배경과 텍스트는 완전 무채색에 가깝고, 강조 색 하나만 채도를 높여 포인트로 사용, 색온도 기본은 중성(그레이스케일)이며 포인트 컬러에서만 쿨 블루 또는 소프트 그린으로 온도가 갈림

## Typography
둥근 끝맺음의 지오메트릭 산세리프, 친근하면서도 단단한 인상. 스케일 히어로 헤드라인이 본문 대비 약 6~7배 크기로 압도적인 크기 차이를 둠, 굵기 헤드라인은 매우 굵은 두께(black/extrabold), 본문과 버튼 텍스트는 중간 두께(medium/semibold), 행간 헤드라인은 글자 높이에 가깝게 좁힌 타이트한 줄간격, 본문 문단은 여유 있는 줄간격, 자간 헤드라인과 본문 모두 기본 자간을 거의 그대로 유지하는 중립적 트래킹. 위계: 헤드라인 한 단계 → 서브카피 한 단계 → 버튼 레이블로 이어지는 3단 수직 위계, 중간 단계 생략 없이 급격한 크기 대비로 눈을 끎

## Spacing
섹션 간격 섹션 간 수직 여백이 화면 높이의 10~15% 수준으로 넉넉함, 컨테이너 패딩 좌우 컨테이너 패딩은 뷰포트 폭의 약 6~8%, 카드 패딩 카드 내부 패딩은 카드 크기 대비 약 6~8% 비율로 여유 있게, 콘텐츠 간격 헤드라인-서브카피-버튼 사이 각 24~32px 간격의 균등한 리듬, hero 여백 헤드라인 상하로 화면의 상당 부분을 비워 텍스트가 숨 쉴 공간을 확보

## Layout
컨테이너 최대 1200~1280px 폭의 중앙 정렬 컨테이너, 좌우 여백은 뷰포트의 약 5~8%, 정렬 히어로 텍스트와 버튼은 가로 중앙 정렬, 로고 바는 가로 전체에 균등 분배, 이미지 배치 제품 UI 스크린샷을 히어로 하단에 크게 배치해 콘텐츠와 겹치며 다음 섹션으로 자연스럽게 이어지는 티저 형태

## Grid
단일 컬럼 중앙 정렬 콘텐츠 위에 하단 로고 바만 가로 flex 그리드로 나열되는 혼합 구조. 섹션 순서: header → hero → logoBar

## Photography
구도 실사진 대신 제품 UI 스크린샷을 피사체로 사용, 화면 일부가 잘려 다음 섹션과 겹치는 크롭 구성, 조명 플랫 UI 캡처라 인위적 조명 없음, 균일한 밝기의 플랫 라이팅, 그레이딩 원본 UI의 채도를 그대로 둔 중립 톤, 별도 필터나 보정 없음, 화각 정면 스크린 캡처 각도(0도), 원근 왜곡 없음, 심도 전체 영역이 고르게 선명한 딥포커스, 흐림 효과 없음, 비율 가로로 넓은 와이드 비율(약 16:9~2:1)로 가로 스크린샷 전체 폭을 채움

## Components
테두리 1px 솔리드 연회색 테두리를 카드와 팝업 요소에 사용, 라운드 버튼은 완전 둥근 알약형, 카드와 모달은 12~20px의 큰 라운드 반경, 그림자 그림자는 매우 옅고 넓게 퍼지는 형태로 부유감만 살짝 부여

## Navigation
가로 일렬 텍스트 메뉴, 일부 항목에 작은 쉐브론 드롭다운 아이콘 동반

## Buttons
완전 둥근 알약형(pill) 버튼, 주 버튼은 단색 채움 + 흰 텍스트, 보조 버튼은 옅은 틴트 배경 + 진한 텍스트

## Forms
라운드 처리된 단순 입력 필드, 레이블은 필드 위 작은 텍스트로 배치

## Cards
큰 모서리 반경의 흰색/옅은 배경 카드, 얇은 외곽선과 미세한 그림자로 구분

## Motion
fade 스크린샷 캡처 특성상 확인 불가하나 알약형 버튼군의 정적 레이아웃으로 미루어 진입 시 옅은 페이드인이 어울림 / reveal 스크롤에 따라 하단 콘텐츠가 순차적으로 드러나는 스테이지드 리빌이 레이아웃과 어울림 / scroll 히어로 이미지가 다음 섹션에 겹치는 레이아웃상 패럴랙스 느낌의 완만한 스크롤 연출이 적합 / hover 버튼 호버 시 배경색이 살짝 어두워지거나 밝아지는 미세한 톤 변화가 자연스러움 / transition 전체적으로 0.2~0.3초의 짧고 부드러운 이징 전환이 컴포넌트 톤과 일치
