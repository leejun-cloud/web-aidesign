## Design Direction
Linear — 분위기: minimal, technical, confident, focused, modern, precise. hero 구조: 중앙정렬 풀블리드 다크 히어로, 대형 헤드라인 2줄 + 서브카피 1줄 아래로 실제 제품 스크린샷(앱 UI 패널)을 뷰포트 하단에서 크롭되게 배치

## Color System
background #0A0A0A / surface #141414 / primary #FFFFFF / secondary #A3A3A3 / accent #5E6AD2 / text #E5E5E5. 채도 거의 무채색에 가까운 저채도 팔레트, 포인트 색만 채도를 살짝 높임, 색온도 전반적으로 차가운 톤의 다크 테마

## Typography
그로테스크 산세리프 계열, 군더더기 없는 기하학적 느낌의 중립적 서체. 스케일 히어로 헤드라인이 매우 크게(화면폭의 상당 부분 차지) 설정되고 본문 대비 비율 차이가 큼, 굵기 헤드라인은 굵은 굵기, 본문/내비는 가벼운~중간 굵기로 대비, 행간 헤드라인은 타이트한 줄간격, 본문 서브카피는 여유 있는 줄간격, 자간 헤드라인은 자간 거의 없음, 내비게이션 텍스트는 살짝 넓은 자간. 위계: 헤드라인-서브카피-내비 3단계로 크기와 명도 대비를 뚜렷하게 구분

## Spacing
섹션 간격 섹션 간 넉넉한 수직 여백, 히어로와 쇼케이스 사이에 큰 공백, 컨테이너 패딩 좌우 컨테이너 패딩이 넓어 콘텐츠가 가장자리에서 충분히 떨어짐, 카드 패딩 플로팅 카드 내부 패딩은 중간 수준으로 콤팩트, 콘텐츠 간격 헤드라인과 서브카피 사이 적당한 간격, 서브카피와 버튼 사이도 유사한 리듬, hero 여백 히어로 상단에 넓은 네거티브 스페이스를 두어 헤드라인이 화면 중하단에 안착

## Layout
컨테이너 콘텐츠 최대폭 약 1200~1280px, 좌우 넉넉한 여백으로 중앙 집중, 정렬 헤더 영역은 좌측 로고/내비 수평 정렬, 히어로 텍스트는 좌측 정렬(가운데 정렬 아님), 버튼 그룹은 우측 상단, 이미지 배치 제품 UI 스크린샷을 히어로 하단에 큰 캔버스로 배치하고 플로팅 플로팅 카드(채팅형 패널)를 우측 하단에 겹쳐 띄움

## Grid
단일 컬럼 중심 세로 흐름, 제품 스크린샷 영역만 내부적으로 사이드바+본문 2열 구조를 가진 앱 UI 그리드. 섹션 순서: header → hero → productShowcase

## Photography
구도 실제 사진이 아닌 제품 UI 캡처 중심, 수평 분할된 패널 구도, 조명 어두운 배경 위에 UI 요소만 은은하게 발광하는 듯한 낮은 대비 조명감, 그레이딩 모노톤 다크 그레이 베이스에 소량의 포인트 컬러(노란 별, 보라 액센트), 화각 정면 스크린 캡처 앵글, 원근 왜곡 없음, 심도 전경 플로팅 카드가 선명하고 배경 UI는 상대적으로 흐릿하게 레이어링, 비율 와이드 가로비율(약 16:9에 가까운 풀블리드 스크린샷)

## Components
테두리 1px 미만의 매우 옅은 반투명 보더로 섹션과 카드 경계 구분, 라운드 버튼은 완전 둥근 알약형, 카드/패널은 중간 정도의 둥근 모서리, 그림자 다크 배경 위 은은한 글로우성 그림자, 강한 드롭섀도우는 없음

## Navigation
가로 일렬 텍스트 링크 내비게이션, 구분자 없이 간격으로만 분리

## Buttons
알약형(완전 둥근) 흰색 배경 버튼과 투명 텍스트형 버튼 두 종류 공존

## Forms
단일 라인 텍스트 입력창이 카드 하단에 내장된 미니멀 채팅 입력 형태

## Cards
모서리가 둥근 다크 그레이 플로팅 패널 카드, 미세한 테두리로 배경과 분리

## Motion
fade 페이지 진입 시 텍스트와 이미지가 부드럽게 페이드인되는 느낌 / reveal 스크린샷 패널이 아래에서 위로 살짝 떠오르며 드러나는 리빌 방식 / scroll 스크롤에 따라 제품 UI 패널이 패럴랙스처럼 느리게 따라오는 느낌 / hover 버튼과 링크에 미세한 밝기 변화 또는 배경색 전환 호버 / transition 전반적으로 빠르지 않고 부드러운 이징의 전환 속도감

## Responsive
브레이크포인트: 640px, 834px, 1440px
